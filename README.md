# 2026 亞洲生技大展 · BIO Asia–Taiwan 2026

> 「亞洲創新・全球影響」— 全球三大生技盛會之一,2026/7/15–19 於台北南港展覽館。這是一個可瀏覽、可搜尋、中英雙語的多頁導覽網站。

本站把 2026 亞洲生技大會(BIO Asia–Taiwan / 亞洲生技大展)的公開資訊整理成一個好讀、好找的靜態網站:大會概覽、成長數據、展覽亮點、講者陣容、論壇與商機媒合、逐日議程、逛展建議、參觀身分對照、參展單位、場地交通與常見問題,還附上幾款生技小遊戲,一頁一主題、各自獨立網址。內容整理自官方網站與公開新聞報導。

## ✨ 功能特色

- 🌏 **雙語切換** — 中文 / English 一鍵切換,整頁(含導覽、頁尾)即時重繪
- 🌗 **深色 / 淺色模式** — 手動切換,並記憶於瀏覽器
- 🧭 **多頁導覽** — 14 個主題頁,共用導覽列,跨頁保留語言與主題
- 🔍 **即時搜尋** — 論壇、講者、參展單位頁可輸入關鍵字立即過濾
- 🏷️ **分類篩選** — 依論壇類型 / 參展類別快速篩選
- 🔗 **深連結** — 論壇、講者項目皆有專屬 `#slug`,可直接分享
- 🗺️ **互動地圖** — 場地與交通頁以地圖標示南港展覽館與周邊交通、住宿
- 📊 **數據圖表** — 歷年規模成長的長條 / 折線圖(純 SVG,無圖表庫)
- 🎮 **小遊戲** — 快問快答、鹼基配對記憶、抓住分子、術語配對,玩中學生技
- 📱 **響應式設計** — 手機、平板、桌機皆適配
- ⚡ **純靜態** — 無後端、無建置工具、載入快、可離線瀏覽

## 🛠 本機使用

```bash
# 1. clone 專案
git clone git@github.com:tingwei161803/bio-asia-taiwan-2026.git
cd bio-asia-taiwan-2026

# 2a. 最簡單:直接開啟首頁
open index.html

# 2b. 或啟動本機伺服器(建議,跨頁連結 / 深連結才完整)
uv run python -m http.server 4173
# 然後瀏覽 http://localhost:4173
```

> 本專案為純靜態網站,不需安裝任何依賴。若要跑本機伺服器,一律使用 `uv`。
